============================================================
  SIPARIS ASISTANI - HIZLI KURULUM REHBERI
============================================================

Bu klasor:  installer\windows
Bu dosya senin Windows bilgisayarinda iki tip kurulumu
yapmak icin gereken her seyi ozetler.

------------------------------------------------------------
  ON HAZIRLIK (sadece bir kere)
------------------------------------------------------------

1) Python 3.10 veya ustu
   - Microsoft Store'dan "Python 3.12" kur (en kolay)
   - VEYA https://www.python.org/downloads/windows/
   - Kurulumda "Add python.exe to PATH" KUTUSUNU ISARETLE!

2) Inno Setup 6 (opsiyonel, .exe installer istiyorsan)
   - https://jrsoftware.org/isdl.php
   - Default ayarlarla kur, "Add to PATH" sor sorma onemsiz
   - Yoksa sorun degil; alttaki "Plan B"yi kullan

------------------------------------------------------------
  DERLEME (build)
------------------------------------------------------------

YONTEM A - Cift Tikla
   - build.bat'e cift tikla
   - Pencere acilip kapanirsa: Plan B'ye gec

YONTEM B (ONERILEN) - Komut Isteminden
   - Dosya gezgininde installer\windows klasorune gel
   - Adres cubuguna yaz:  cmd
   - Acilan cmd penceresine yaz:   build.bat
   - Hata olursa pencere KAPANMAZ, hatayi gorursun

YONTEM C - PowerShell
   - Sag tikla "PowerShell penceresi burada ac"
   - Yaz: cmd /c .\build.bat ; pause

------------------------------------------------------------
  CIKTI
------------------------------------------------------------

[+] PyInstaller cikti klasoru:
    Proje\dist\SiparisAsistani\
    -> Bu klasorun TAMAMI tasinabilir bir uygulamadir.
       Icindeki SiparisAsistani.exe'ye cift tikla, calisir.
       Python kurulu olmayan herhangi bir Windows'a kopyala.

[+] Inno Setup yuklu ise:
    installer\windows\Output\SiparisAsistaniSetup.exe
    -> Tek dosya. Hedef Windows'ta cift tikla, kurulum
       sihirbazi acilir, masaustune kisayol koyar.

------------------------------------------------------------
  HEDEF BILGISAYARDA KURULUM
------------------------------------------------------------

PLAN A - Inno Setup ile uretilmis .exe varsa
  1) SiparisAsistaniSetup.exe'yi USB ile gotur
  2) Cift tikla, "Evet"e bas (admin), Ileri-Ileri-Bitir
  3) Acilan Notepad'e Supabase URL ve SECRET KEY yapistir, kaydet
  4) Masaustundeki "Siparis Asistani" kisayoluna tikla

PLAN B - Sadece dist klasoru varsa (Inno Setup yok)
  1) dist\SiparisAsistani\ klasorunu komple zip'le
  2) USB ile hedef bilgisayara goturup C:\SiparisAsistani gibi
     bir yere ac (Program Files'a koyma, izin sorunu olur)
  3) .env.example'i .env olarak kopyala, Notepad ile ac,
     Supabase URL ve SECRET KEY'i doldur
  4) SiparisAsistani.exe'ye sag tikla > "Kisayol gonder
     > Masaustu" ile masaustune kisayol koy
  5) Kisayola cift tikla, program acilir

------------------------------------------------------------
  SIK YASANAN HATALAR
------------------------------------------------------------

> "build.bat'e tikladim, pencere acilip kapaniyor"
  Cozum: Yontem B'yi kullan (cmd'den calistir). Hata gorunur.

> "Python bulunamadi"
  Cozum: Microsoft Store'dan "Python 3.12" kur. Kurulum
  sirasinda "Add python.exe to PATH" sec.

> "pip install ... SSL hatasi"
  Cozum: Sirket aginda olabilirsin. Mobil hotspot ile dene.

> "PyInstaller failed: ImportError: ..."
  Cozum: Bana hata satirini ilet, spec'e hidden import ekleyim.

> "PyInstaller bitti ama exe acilmiyor"
  Cozum: dist\SiparisAsistani\ klasorunde cmd ac, yaz:
         SiparisAsistani.exe
  Hata mesajini bana ilet.

> "Antivirus exe'yi sildi (Windows Defender / Avast)"
  Cozum: PyInstaller exe'leri sik sik false positive verir.
  Antivirusten istisna ekle veya .exe'yi imzalat (codesign).

> "Inno Setup bulunamadi" yazisi gordum
  Cozum: Sorun degil; Plan B (zip'leyip tasi) gayet calisir.
